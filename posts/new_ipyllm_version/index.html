Bringing sessions to ipyllm

October 30, 2026 One-minute read
Juan Pablo De La Cruz Gutiérrez
Ipyllm • Reproducibility • Ipython • LLMs

When doing data exploration it is also important to remember how you obtained the results. This is the main motivation behind this new version of ipyllm.

You can now start recording a session with %llm --save FILE.py. From that moment on, all your prompts will be saved as comments followed by the corresponding code produced by your agent in that file. %llm --save off stops the recording.

You can rerun a session and continue recording with %llm --resume FILE.py.

There are some minors new features which are described in the documentation as well.

New ipyllm release 0.4.0

November 3, 2026 One-minute read
Juan Pablo De La Cruz Gutiérrez
Ipyllm • Ipython • LLMs • Release

This new version brings post-mortem assisted debugging, meaning, instead of launching the pdb debugger as IPython usually does, it captures the trace call and directly prompts an AI agent to diagnose the root cause.

Adding more information to the context can help the agent produce better responses. As many tools do, you can now add a file to the context by typing @, followed by the file name. Autocomplete is supported, but fuzzy search not yet. That is left for another release.

Further details in the online documentation and the blog.

This new release is available at github and pypi.
